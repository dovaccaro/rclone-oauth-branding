# rclone-oauth-branding

Soporte público mínimo para las páginas de branding OAuth de una integración personal de rclone.

Este repositorio es auxiliar y no canónico. No contiene configuración operativa, credenciales, tokens, registros ni información respaldada.

## Atribución

Rclone Backup Drive utiliza [rclone](https://rclone.org/), software de código abierto distribuido bajo la [licencia MIT](https://rclone.org/licence/), creado por Nick Craig-Wood y desarrollado y mantenido con la participación de la comunidad de rclone.

Rclone Backup Drive es una aplicación personal e independiente. No es una aplicación oficial del proyecto rclone ni está afiliada o respaldada por dicho proyecto.
